# 리센느 상품 주문 계산기

GitHub Pages용 정적 웹앱입니다.

## 배포 방법
1. 이 폴더의 파일들을 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch를 `main`, Folder를 `/(root)`로 선택하고 Save 합니다.
5. 잠시 후 생성된 GitHub Pages 주소로 접속하면 됩니다.

입력 수량은 브라우저의 localStorage에 자동 저장됩니다. 같은 기기/브라우저에서 다시 열면 복원됩니다.
